How it works

  1. 1

    Load data

    Start with the built-in Shapes, or drop a folder of your own images. Files are decoded in the page and never uploaded.

  2. 2

    Train

    Pick a preset and press Start. In the browser a 218k-parameter demo model trains in about a minute; the desktop app trains real encoders with PyTorch from the same config file.

  3. 3

    See what it learned

    Rotate the embedding cloud, check the collapse detector, find nearest neighbours, then score it with a few labels.

What a JEPA learns

A joint-embedding predictive architecture never reconstructs pixels. It learns an embedding in which different views of the same thing land close together, and LeJEPA adds one rule that keeps that embedding from cheating.

Views

Each image is cropped, recoloured and flipped into two large global views and several small local views. They share content, not pixels.

Predict the centre

The encoder maps every view to a vector. The prediction loss pulls each vector toward the mean of the global views: whatever survives cropping is what matters.

Stay Gaussian

Agreement alone is solved by mapping everything to one point. SIGReg tests random 1-D projections of the batch against N(0, 1), so the embedding must stay spread out and isotropic.

In the browser, or on your machine

The website is the same app as the desktop build. In a browser it trains a small demo model locally; the desktop app runs full PyTorch training on your CPU or GPU.
