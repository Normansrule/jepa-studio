An AI agent that runs on your computer.

JEV answers questions, writes and runs code, makes images and narrated videos, and simulates physics, with language models from your own Ollama. Code runs in a sandbox folder; anything beyond it asks you first. JEV Studio also pretrains and inspects JEPA models on your own unlabeled data.

What JEV does

One chat, many tools, all local. JEV picks the tool, shows you every call as it runs, and keeps the files it makes in the conversation.

  • Answer

    Explains, summarizes and quotes the documents and files you give it.

  • Code

    Writes Python, runs it in a sandbox folder with time and memory limits, and reads the output.

  • Images

    Charts, diagrams, slides, renders, and image models you install yourself.

  • Video

    Narrated explainers with local text-to-speech, and highlight cuts of your own footage.

  • Physics

    A ray-traced Kerr black hole, N-body gravity, pendulums and waves, as stills or video.

What it may do on its own

Every tool declares a risk level, and the backend, not the model, decides what runs. Nothing leaves your computer unless you approve it.

  • Read only

    Runs at once. Changes nothing.

    Answering, maths, listing the conversation's files.

  • Sandbox

    Runs at once, inside the conversation's own folder, with limits.

    Running code, renders, assembling a video.

  • Asks first

    Waits for you: Approve once, Approve for this session, or Deny.

    The network, files outside the sandbox, installing or deleting, downloading models.

The full safety model, and what it does not protect against

JEPA models, on your own data

The studio's second half pretrains LeJEPA encoders on your unlabeled images, video or time series, shows what they learned, and plans in a learned world model. A joint-embedding predictive architecture never reconstructs pixels: it learns an embedding in which different views of the same thing land close together.

Views

Each image is cropped, recoloured and flipped into two large global views and several small local views. They share content, not pixels.

Predict the centre

The encoder maps every view to a vector. The prediction loss pulls each vector toward the mean of the global views: whatever survives cropping is what matters.

Stay Gaussian

Agreement alone is solved by mapping everything to one point. SIGReg tests random 1-D projections of the batch against N(0, 1), so the embedding must stay spread out and isotropic.

Train a JEPA in three steps

  1. 1

    Load data

    Start with the built-in Shapes, or drop a folder of your own images. Files are decoded in the page and never uploaded.

  2. 2

    Train

    Pick a preset and press Start. In the browser a 218k-parameter demo model trains in about a minute; the desktop app trains real encoders with PyTorch from the same config file.

  3. 3

    See what it learned

    Rotate the embedding cloud, check the collapse detector, find nearest neighbours, then score it with a few labels.

In the browser, or on your machine

The website is the same app as the desktop build. In a browser it trains a small JEPA demo model and runs the Science tab; JEV and full PyTorch training need the desktop app.

Download

Installers are built by CI and attached to each GitHub release, with SHA-256 checksums. The app only listens on 127.0.0.1 and never uploads your data. For JEV, also install Ollama and download one model; the app's Doctor shows the commands.

ollama pull qwen2.5-coder:7b   # JEV's default model (about 4.7 GB)
pip install "jepa-studio[jev]"  # the Python package: JEPA tools and the JEV backend
jepa-studio serve             # the same UI on 127.0.0.1, backed by PyTorch and JEV
