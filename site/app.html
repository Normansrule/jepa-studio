JEV runs on your computer

JEV is a local AI agent. It answers questions, writes and runs code, makes images and narrated videos, and simulates physics, using language models that Ollama serves on your own machine. A website can't reach Ollama or run programs, so JEV needs the desktop app.

Get the desktop app

Free and open source, for Windows, macOS (Apple silicon) and Linux. You also need Ollama (free) and one model, about 5 GB. The JEPA tabs and Science work in this browser.

What JEV can do

  • Answer and explain, quoting the files and docs it read.
  • Write and run code in a sandbox folder, and show you the output.
  • Make images and narrated videos from slides, renders and your own footage.
  • Simulate physics: a ray-traced spinning black hole, gravity, pendulums, waves.

What it may do without asking

  • Read only runs at once: answering, maths, reading its own workspace.
  • Sandbox runs at once, but only inside the conversation's folder, with time and memory limits.
  • Asks first network, your files, installing, deleting: never without your OK.

      Where the model files are

      Ollama, not JEV, stores the weights: a blobs/ folder (files named by SHA-256) and manifests/. Copying that folder to another computer copies your models.

      Ollama's default models folder
      SystemDefault folder
      Windows%USERPROFILE%\.ollama\models
      macOS~/.ollama/models
      Linux (systemd service)/usr/share/ollama/.ollama/models
      Linux (ollama serve), WSL~/.ollama/models

      To keep them on another drive, set OLLAMA_MODELS to a folder before Ollama starts, then restart Ollama. Windows: a user environment variable (Settings, System, About, Advanced system settings, Environment Variables). macOS: launchctl setenv OLLAMA_MODELS /Volumes/Models/ollama. Linux: sudo systemctl edit ollama, add Environment="OLLAMA_MODELS=/data/ollama-models" under [Service], make the folder owned by the ollama user, restart the service.

      Settings

      Model server

      Normally http://127.0.0.1:11434 (this computer).

      Your prompts, files and tool results would leave this computer. Everything JEV sends to the model goes to that address, over plain HTTP unless it is https. Use it only for a machine you control on a network you trust. The backend also refuses it until "allow_remote_ollama": true is set in settings.json by hand.

      Sandbox limits for each code run

      Network

      Off (recommended): code that wants the network stops and asks you each time. On: the sandbox’s network block is lifted and that one question is skipped; downloads, installs, shell commands, sending data off the machine and deleting still ask every time, because they are separate rows in the approval table.

      Code JEV writes can then reach the internet and your local network without a prompt.

                  What you are seeing

                  The dark disc is the black hole's shadow: every ray of light aimed inside it falls in. The thin bright ring at its edge is light that orbited the hole before escaping.

                  The disk lies flat around the hole, yet its far side shows above and below the shadow: gravity bends that light over the top and under the bottom (gravitational lensing).

                  The side of the disk moving toward you is brighter and bluer (Doppler shift and beaming); the side moving away is dimmer and redder. The film Interstellar left these out to keep its black hole symmetric; switch them off to see that look.

                  Spin drags space around with the hole, so prograde orbits get closer and one edge of the shadow flattens.

                  What you are seeing

                  Every body pulls on every other one with Newton's inverse-square gravity. Close encounters fling bodies out; pairs that lose energy settle into orbits around each other.

                  What you are seeing

                  A pendulum hanging from a pendulum is chaotic: change a starting angle by a fraction of a degree and after a few swings the motion is completely different. The equations are simple; prediction is not.

                  What you are seeing

                  The two-dimensional wave equation on a membrane: a source pushes the surface up and down, ripples spread at the wave speed, reflect from the edges and interfere. Damping slowly takes energy out.

                  Probe settings

                  10%

                  20% of the images are held out for scoring; the labeled subset comes from the rest.

                  • Linear probe: softmax regression on standardized features, full-batch Adam, 100 epochs.
                  • k-NN: cosine similarity, k = 20, majority vote, ties go to the nearest neighbour.
                  • Random-init: the same MLP, untrained.
                  • Supervised: the same MLP trained with cross-entropy on the same labeled subset.
